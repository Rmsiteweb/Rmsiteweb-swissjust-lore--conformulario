## 🚀 Publicar en GitHub Pages

1. Subir `index.html` al repositorio
2. **Settings → Pages → Deploy from branch → main → / (root)**
3. Listo en 1-2 minutos

## 🔑 Activar la IA

Buscar en `index.html` esta línea:
```
'x-api-key':'sk-ant-TU_KEY_AQUI',
```
Reemplazar `sk-ant-TU_KEY_AQUI` con tu API key de Anthropic.
